## 📖 세계관 및 스토리 (Lore & Worldview)

외계 해양 행성 **'칼립소-9 (Calypso-9)'**의 수심 1,500m 초심해 마리아나급 해구 바닥에서 기원전 외계 선구자(Precursor) 문명의 미확인 양자 신호가 포착되었습니다.

당신은 심해 탐사선 **'노틸러스-IV (Nautilus-IV)'**의 유일한 조종사로서, 표해수대의 연구 모선 **'CSS ORCA'**를 떠나 빛이 도달하지 않는 칠흑 같은 심연으로 잠항해야 합니다. 맹렬한 수압, 부족한 산소, 그리고 잠수정의 엔진 소음과 조명을 쫓아 돌진하는 미지의 거대 심해 괴수 **'하달 레비아탄'**의 위협을 뚫고 3개의 외계 암호 키를 수집하여 해구 최심부의 신호기를 활성화하십시오!

## 🎮 주요 시스템 & 특징 (Core Systems)

### 1. 2D 캔버스 수심 수직 탐사 & 동적 시야 (0m ~ 1,600m)
- **거대한 수직 맵**: 표면 모선(0m)부터 1,600m 해구 바닥까지 이어지는 연속적인 심해 지형.
- **다이내믹 암전 & 조명 시스템**: 수심 300m 이상은 97% 이상의 완전한 칠흑으로 전환되며, 잠수정의 고출력 LED 전방 탐조등 빛 원추(Cone of Light) 및 선체 내부 계기판 조명만 투과됩니다.
- **능동 소나 핑 (Active Sonar Ping - `[F]` 키)**:
  - 음파 파동이 850m 반경으로 팽창하며 10초간 주변 지형 암초와 미확인 생물체를 선명한 **에메랄드빛 레트로 그린 와이어프레임**으로 시각화합니다.
  - **주의**: 소나 발사 시 순간적으로 75dB 이상의 음향 스파이크가 발생하여 주변 포식자의 주의를 끕니다!

### 2. 4대 생존 게이지 & 수압 붕괴 메커니즘
- **선체 내구도 (Hull Integrity)**: 지형 충돌, 포식자 공격, 수압 초과 데미지로부터 선체를 방어합니다. 선체 손상 시 조종석 유리에 균열이 가며 경보 사이렌이 울립니다.
- **산소량 (Oxygen)**: 승무원의 생명 유지 장치. 시간이 지남에 따라 서서히 소모되며 고갈 시 사망합니다.
- **배터리 전력 (Power)**: 추진 엔진 가동, 헤드라이트, 소나 핑, 채굴 레이저, EMP 펄스 발사 시 소모됩니다.
- **수심 수압 (Crush Depth)**: 내압 선체 티어에 따른 안전 한계 수심을 초과하면 선체가 삐걱거리는 금속 신음(Creak)과 함께 초당 지속 데미지를 입습니다.

### 3. 정숙 주행 & 생태계 AI (Silent Running)
- **정숙 주행 (`[Q]` 헤드라이트 소등 + 저속 운항)**:
  - 조명을 끄고 엔진 속도를 줄이면 잠수정 음향이 20dB 이하로 떨어져 `SILENT RUN [은신]` 모드로 진입합니다.
  - 시각이 퇴화하고 청각/소나 감각이 극도로 발달한 **하달 레비아탄(The Hadal Leviathan)**과 **심해 프라울러**의 추적을 회피할 수 있습니다.
- **해양 생태계**:
  - 발광 해파리 (Aura Medusa): 주변을 은은하게 비추는 온순한 플랑크톤 섭식 생물.
  - 유령 가오리 (Phantom Ray): 심해 조류를 타는 거대한 연골어류.
  - 심해 프라울러 (Abyss Prowler): 조명과 소음에 반응해 고속으로 돌진하는 중형 포식자.
  - 하달 레비아탄 [스킬라] (Apex Predator): 16마디 척추 관절을 지닌 40m급 초거대 맹수. 묵직한 포효와 함께 잠수정을 파쇄합니다.

### 4. 심해 채굴 & 자원 환전 (Mining & Economy)
- **고출력 채굴 레이저 / 로봇 집게 암 (`마우스 좌클릭`)**:
  - 암초 벽면에 박힌 희귀 광맥을 레이저로 타격하여 파쇄.
  - 유출된 부유 광물 조각은 잠수정의 자력 흡인 시스템으로 화물창에 자동 적재됩니다.
  - 광물 종류: 티타늄(60 CR), 구리(120 CR), 석영(200 CR), 리튬(380 CR), 다크매터 결정(750 CR).

### 5. 모선 기지 도킹 & 5대 테크트리 개조 (Mothership & Upgrades)
- 수면(0m)의 연구 모선 **'CSS ORCA'** 크래들에 도킹 시 선체 수리, 배터리 충전, 산소 완충 및 채굴 자원 일괄 매각 정산.
- **잠수정 업그레이드**:
  1. **내압 선체 (Pressure Hull)**: Mk I (400m) ➔ Mk II (800m) ➔ Mk III (1,200m) ➔ Mk IV (1,600m 초심해 허용)
  2. **핵융합 배터리 (Fusion Battery)**: 100 kWh ➔ 180 kWh ➔ 300 kWh ➔ 500 kWh
  3. **초고휘도 LED 탐조등 (Searchlight)**: 조사 거리 및 시야각 3단계 확장
  4. **이온 추진기 (Ion Thruster)**: 추진 속도 증가 및 엔진 소음 대폭 억제
  5. **충격파 방어 EMP 펄스 (`[SPACE]` 키)**: 360도 전자기 방출로 포식자 기절 및 밀쳐내기
  6. **자가 수리 나노봇 (Nanite Auto-Repair)**: 배터리 여유 시 지속 선체 복구
  7. **화물창 적재 모듈 (Cargo Expansion)**: 15슬롯 ➔ 30슬롯 ➔ 50슬롯 확장

### 6. Web Audio API 프로시저럴 사운드스케이프
- 외부 음원 파일 없이 브라우저 Web Audio API 오실레이터와 바이쿼드 필터로 실시간 합성되는 심해 음향:
  - 54Hz/55.5Hz 듀얼 디튠 수중 압력 앰비언스 험(Hum)
  - 추진기 스크루 기포 버블링 & 저역 통과 엔진 럼블
  - 1350Hz ➔ 750Hz 지수 감쇠 + 450ms 스테레오 딜레이 소나 핑 & 메아리
  - 수압 초과 시 재생되는 금속 선체 삐걱거림 및 비상 경보 사이렌
  - 레비아탄의 심해 포효, 채굴 레이저 방전음, EMP 충격파

### 7. 완결성 & 실시간 저장 (Persistence)
- 3개의 선구자 암호 키를 수집하여 1,500m 해구 바닥의 주 송신기 코어를 가동하면 승리 엔딩 및 탐사 결산 리포트 제공 (자유 탐사 계속 가능).
- 크레딧, 잠수정 업그레이드 레벨, 인양한 외계 암호 키, 해양 도감(Codex) 및 통계가 `localStorage`에 자동 실시간 동기화.

### 8. 완벽한 다국어 지원 (한국어 / English i18n)
- **한국어(기본 설정)** 및 **English** 실시간 원클릭 전환 지원 (`[🌐 한국어]` / `[🌐 English]` 버튼).
- UI, HUD 게이지, 조작 안내, 모선 거래소, 업그레이드 트리, 해양 도감, 지령 텍스트, 경보 알림 티커까지 100% 매끄러운 이중 언어 현지화.
- 선택한 언어는 `localStorage`에 자동 영구 저장.

## 🕹️ 조작법 (Controls)

| 키 / 입력 | 동작 |
|---|---|
| **W / A / S / D** (또는 방향키) | 잠수정 360도 전방위 이온 추진 기동 |
| **마우스 이동** | 탐조등 조향 및 채굴 레이저/집게 암 조준 |
| **마우스 좌클릭 (Hold)** | 채굴 레이저 발사 및 광맥 파쇄 |
| **Q / E** | 헤드라이트 켜기/끄기 (소등 시 정숙 주행 모드) |
| **E** | 수면 모선 접근 시 '모선 기지 도킹' |
| **F** | 능동 소나 핑 (850m 반경 와이어프레임 탐지) |
| **SPACE** | 충격파 EMP 펄스 발사 (포식자 무력화 / 개조 시) |
| **C** | 심해 생물체 & 광물 & 유적 조사 도감 (CODEX) 열기 |
| **M** | 모선 CSS ORCA 위치 및 수심/거리 항법 핑 |

## 🗺️ 수심별 바이옴 가이드 (Biomes)

1. **표해수대 (0m ~ 150m: 모선 해역)**: 에메랄드빛 햇살이 비치는 온화한 암초. 티타늄 광맥과 모선 도킹 크래들.
2. **중심해대 (150m ~ 450m: 황혼의 해초 동굴)**: 푸른빛이 희미해지는 황혼 지대. 발광 해파리와 구리/석영 광맥. [선구자 침몰 제단 - 암호 키 I]
3. **점해수대 (450m ~ 900m: 암흑 해구)**: 완전한 칠흑의 시작. 400℃ 열수분출구와 위협적인 심해 프라울러, 리튬 광맥.
4. **심해저대 (900m ~ 1,300m: 레비아탄 공허)**: 거대 해양 뼈무덤과 다크매터 결정. 40m급 하달 레비아탄이 소리를 듣고 배회함. [레비아탄 무덤 성소 - 암호 키 II]
5. **초심해 하달 해구 (1,300m ~ 1,600m: 선구자 신전)**: 극한의 압괴 수압. [양자 첨탑 성소 - 암호 키 III]과 최심부 [선구자 주 송신기 코어].

## 🛠️ 기술적 특징 (Technical Details)

- **Zero External Dependencies**: 외부 이미지, 사운드 파일, CSS/JS 라이브러리(Three.js, Pixi.js, Howler.js 등)를 전혀 사용하지 않는 순수 Vanilla Web 기술 100%.
- **Single File Self-Contained**: 단 하나의 `index.html` 파일로 오프라인 및 모든 모던 브라우저에서 즉시 실행 가능.
- **High-Performance Canvas 2D**: 60 FPS 유지를 위한 오프스크린 캔버스 라이팅 마스크 버퍼링 및 파티클 풀링.
- **Web Audio API Direct Synthesis**: 브라우저 오디오 컨텍스트 정책에 맞춘 유저 제스처 스타트업 및 모듈식 음향 합성 파이프라인.
